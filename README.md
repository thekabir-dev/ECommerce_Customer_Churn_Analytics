# E-Commerce Customer Churn Prediction & Analytics with AI

**IBM SkillsBuild Data Analytics with AI Internship 2026 Project**

## Project Overview
This project focuses on identifying key drivers of customer attrition in an e-commerce ecosystem using Exploratory Data Analysis (EDA) and Machine Learning techniques. By building a Random Forest classification model, this project predicts customer churn and delivers actionable insights for targeted retention strategies.

---

## Dataset Information
* **Dataset Used:** Synthesized E-Commerce Customer Analytics Dataset
* **Dataset Features:**
  * `CustomerID`: Unique identifier
  * `Age`: Age of customer
  * `Tenure_Months`: Duration of subscription/account age
  * `Monthly_Spend`: Average monthly transaction amount
  * `Support_Tickets`: Count of raised support issues
  * `Discount_Usage`: Binary indicator of promo usage
  * `Satisfaction_Score`: Customer rating (1-5)
  * `Churn`: Target variable (0 = Retained, 1 = Churned)
